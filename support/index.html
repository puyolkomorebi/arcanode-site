ARCANODE サポート プライバシー

サポート

「ARCANODE」についてのご質問・不具合のご報告は、GitHub の Issues からお寄せください（GitHub のアカウントが必要です）。いただいた内容は公開されるので、個人情報は書かないでください。

不具合のご報告には、端末の機種、iOS のバージョン、依頼の番号（例：2-5）を添えていただけると助かります。

よくある質問

言語を変えたい
タイトル画面の右上、または依頼帳のいちばん下の「設定」から選べます。
記録を最初からにしたい
「設定」→「記録を消す」を2回続けて押します。消した記録はもとに戻せません。
解けない依頼があります
依頼の画面の「師匠のメモ」を読んでください（3枚目は答えです）。読むと、その依頼で取れる★が減ります。
音が出ません
端末の消音スイッチと音量、「設定」の音楽・効果音を確かめてください。

English

For questions or bug reports, please open an issue on GitHub Issues (a GitHub account is required). Issues are public, so please don't include personal information. For bug reports, please include your device model, iOS version, and the request number (e.g. 2-5).

How do I change the language?
Open Settings (top right of the title screen, or the bottom of the request list).
How do I start over?
Settings > Delete progress, pressed twice. Deleted progress cannot be restored.
I'm stuck on a request.
Read the Master's Notes on the request screen (the third note is the answer). Reading them lowers the stars you can earn on that request.
